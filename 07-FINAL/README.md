# 07-FINAL

Board pack only.

**Assessment records and certificates are deliberately NOT in this repository.**

This repo is public. Intern assessment records, marks, feedback and
certificates are personal data about identifiable people and do not belong in
a world-readable repository. They live in a separate private repository,
`SYCOM-INTERNSHIP-ASSESSMENT`, visible to the CISO and mentors only.

If you find yourself about to commit a mark, a rubric score, a feedback note
or a named certificate here, stop. It goes in the other repo.
